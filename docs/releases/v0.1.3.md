# v0.1.3

## Highlights

- Remote bundles include `ctl` and `ctmux`. Use `ctl who` to see live
  clients by device label and app, and `ctmux clients` to see who is viewing
  sessions and which sessions have no viewers.
- Port forwarding supports TCP, UDP, and both protocols on the same port.
  Terminal, task, and UDP forwarding connections can share one SSH transport.
- `ctlup` manages component installs and updates for local and remote hosts.
  The desktop shows update progress, and Linux ARM64 development bundles can
  build with Zig without Docker.
- Nightly follows `main` and includes the commit date in `YYYYMMDD` format.
  `ctlup release list --channel dev` shows recent PRs and their build status.
  `ctlup release view --pr PR_NUMBER` and `ctlup update --pr PR_NUMBER` work
  with PR builds. `ctlup release build --pr PR_NUMBER` requests a build through
  authenticated `gh`.
- Desktop reconnects preserve input control. Closing a terminal view releases
  its attachment resources.

### Changes since v0.1.2

- `ctmux` advances from `1.2.22` (build 22) to `1.3.23` (build 23). It adds
  `list_session_clients` and `session_clients`, and accepts optional
  `client_identity` on attach and resume. Earlier contracts retain their
  existing request and response shapes.
- `ctld` advances from `1.1.16` (build 16) to `1.2.18` (build 18). Contract
  `1.2.17` adds UDP, `any`, and protocol-aware listener discovery. Contract
  `1.2.18` adds `open_service` and `service_opened` for terminal, task, and UDP
  services over a shared SSH transport. Earlier forwarding contracts retain
  TCP behavior.
- `ctl_identity` advances from `1.0.3` (build 3) to `1.1.4` (build 4), and
  `ctl_remote_vpn` advances from `1.0.1` (build 1) to `1.1.2` (build 2).
  Their new contracts accept optional `client_identity` during selection.
  Earlier contracts retain their existing selection shapes.
- `ctl_forwarding` starts at `1.0.1` (build 1) with single-peer datagram framing.
  Contract `1.0.2` (build 2) multiplexes datagrams and close frames for independent
  peers. The single-peer contract remains supported.
- `ctl_transport` starts at `1.0.1` (build 1) with a service selector over
  Yamux streams for terminal, task, and UDP forwarding. The standalone
  `connect` and `forward-udp` endpoints remain supported.
