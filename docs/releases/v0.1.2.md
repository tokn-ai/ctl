# v0.1.2

## Highlights

- A simpler terminal workspace with host colors, clearer session icons, and
  quick sidebar access to hosts, tasks, port forwarding, and VPN.
- Open terminal links with Cmd-click or Ctrl-click, including wrapped URLs.
  Modifier-drag selects and copies locally, including inside mouse-enabled
  programs. Selection and copy behavior are configurable.
- Disconnected terminals keep their screen available for reading and copying.
  Quiet recovery stops after 30 seconds; an explicit reconnect starts a fresh
  attempt. History loading no longer produces false or stale warnings.
- Retained history preserves colors and attributes, with history position and
  session statistics. Keyboard shortcuts work reliably, and new tabs open after
  the current session.
- Temporary SSH destinations and caller-owned credentials make one-off
  connections easier. Host trust, helper selection, component updates, and port
  forwarding are more reliable; components can be stopped with confirmation.
- Native Windows CLI and daemon support includes OpenSSH routes and managed
  port forwarding. Windows desktop support remains pending.

Changes since v0.1.1:

- `ctmux`: `1.1.20` (build 20) to `1.2.22` (build 22). Contract `1.2.21`
  adds styled paged history; `1.2.22` adds the optional `session_history` field
  to `heartbeat_ack`. Contracts before `1.2.21` retain plain history; contracts
  before `1.2.22` retain the original heartbeat response.
- `ctl_maintenance`: `1.1.3` (build 3) to `1.2.4` (build 4). Adds
  `prepare_ctmux_stop`, `stop_prepared`, and `stopped` for separately confirmed
  remote component stop. Stop requires `1.2.4`; earlier restart and inspection
  contracts retain their existing shapes and behavior.

Every earlier published contract in the same major remains supported. The full
supported sets for protocols with multiple published contracts are:

- `ctmux`: `1.0.13`, `1.1.14`, `1.1.15`, `1.1.16`, `1.1.17`, `1.1.18`,
  `1.1.19`, `1.1.20`, `1.2.21`, `1.2.22`.
- `ctld`: `1.0.12`, `1.1.13`, `1.1.14`, `1.1.15`, `1.1.16`.
- `ctld_helper`: `1.0.1`, `1.1.2`, `1.1.3`, `1.1.4`, `1.1.5`.
- `ctl_maintenance`: `1.0.2`, `1.1.3`, `1.2.4`.

Each of the other six protocols supports only the single contract listed as its
latest contract above. Those contracts and their internal builds are unchanged
from v0.1.1.
